# 8-Bit ALU Design using Verilog

**Author:** BOMMI YASWANTH NAIDU (YASWANTHBOMMI)
**GitHub:** https://github.com/YASWANTHBOMMI/verilog---alu---design
**Course:** Final-year Electronics and Communication Engineering

### 📌 Aim
To design and verify an 8-bit Arithmetic Logic Unit (ALU) using Verilog HDL.

### ⚙️ Operations Implemented
| Opcode | Operation |
|---|---|
| 000 | ADD |
| 001 | SUB |
| 010 | AND |
| 011 | OR |
| 100 | XOR |
| 101 | NOT |
| 110 | Left Shift |
| 111 | Right Shift |

### 📁 Files
- `design.sv` - Main ALU Verilog code
- `testbench.sv` - Testbench for simulation

### 🛠️ Tools Used
- Verilog HDL
- EDA Playground
- GitHub

### ✅ Result
All operations verified successfully through simulation.
